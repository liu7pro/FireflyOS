Design Principles

Lean, not stripped

FireflyOS changes the invisible weight of Windows, not the features you rely on.

01

Fewer preinstalled apps

Redundant apps and unnecessary background services are removed to reduce boot and idle load.

02

Core kept intact

Everyday features, drivers and Windows Update remain complete, so daily use is unaffected.

03

Lower resource use

Memory, CPU and disk are tuned so older machines can stay responsive.

04

Native experience

Windows keeps its original interaction and visual language — nothing new to relearn.

05

Stability first

Changes stay restrained. Stability comes before stripping anything further.

06

Kept current

DomeOS Team keeps tracking and fixing issues. Release notes live on this site.
